# Changelog

## 0.4.0

- Add theme-aware comparison tables with spaced rows and colored columns.
- Add process nodes, directional and dashed connectors, cycle returns, hub layouts and focus highlighting.
- Add code/output demo panels with controls, status styling and a printable output fallback. Execution remains application code.
- Make plain and card table defaults overridable without `!important` while preserving their default appearance.
- Preserve nested print rules, comments and fallback declarations in the Tailwind plugin using PostCSS.
- Add gallery examples, component documentation and automated build/plugin checks.
- Correct the documented theme variable prefix to `--rlab-`.
